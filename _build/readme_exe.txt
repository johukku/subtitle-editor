  字幕エディター  v1.0
  ── 字幕を、音を聞きながら直すソフト ──

■ これは何？

  字幕ファイル（SRT / VTT / ASS）を開いて、本文と時刻を直し、
  保存するか、動画に焼き込むツールです。

  ・動画や音声を一緒に開くと、その字幕の区間だけを聞き直せます
  ・波形と、その時刻の 1 コマ（字幕を重ねた状態）を見ながら直せます
  ・長すぎる行、速すぎる字幕、時間の重なりなどに印が付きます
  ・Whisper 字幕作成ツールの出力や、YouTube の自動生成字幕を
    直す用途を想定しています


■ 動作に必要なもの

  ・Windows 10 / 11（64bit）
  ・インターネット接続（初回だけ。FFmpeg の取得に使います）
  ・空き容量 約 300 MB（下記の部品を置くため）

  FFmpeg が無くても、字幕の編集と保存はできます。
  音声の再生・波形・コマの表示・焼き込みに FFmpeg を使います。

■ 使い方
────────────────────────────────────────────────────────────

  1. 「字幕エディター.exe」をダブルクリック

     初回だけ、動作に必要な部品（FFmpeg）を取得してよいか聞かれます。
     「はい」を押してください。取得には数分かかります。

  2. 「字幕を開く...」で字幕ファイルを開く

     同じ場所に同じ名前の動画があれば、一緒に開くか聞かれます。
     動画を先に開いても構いません（字幕のほうを聞かれます）。
     窓にファイルをドラッグ＆ドロップしても開けます。

  3. 一覧から字幕を選んで直す

     ・右の欄で本文と開始・終了を直します
     ・「この字幕を再生」（Ctrl+Enter）で、その区間だけ聞けます
     ・「◀今」を押すと、いまの再生位置が開始・終了に入ります
       （キーボードなら [ と ]）
     ・下の波形の帯をドラッグしても時刻を動かせます
     ・Ctrl+↓ / Ctrl+↑ で次・前の字幕へ

  4. 「保存」（Ctrl+S）

     開いた形式のまま上書きします。最初の上書きのときだけ、
     元のファイルを「（編集前）」という名前で同じ場所に残します。
     別の形式にしたいときは「別名で保存...」です。

  5. 動画に焼き込みたいときは「動画に焼き込む...」

     字幕を映像に描き込んだ動画を、元の動画と同じ場所に
     「（動画名）_字幕入り.mp4」として書き出します。
     元の動画は書き換えません。


■ 主なキー操作

  Space          再生 / 停止（本文の入力中は Ctrl+Space）
  Ctrl+Enter     選んでいる字幕の区間だけ再生
  Ctrl+↓ / ↑     次 / 前の字幕
  [  /  ]        開始 / 終了をいまの再生位置に
  Ctrl+D         本文のカーソル位置で分割
  Ctrl+J         次の字幕と結合
  Ctrl+Z / Y     元に戻す / やり直す
  Ctrl+H         検索・置換
  F3             次の警告へ
  Alt+← / →      3 秒戻る / 進む

  波形は、ホイールで移動、Ctrl+ホイールで拡大縮小です。


■ 一覧の印について

  ！ … 直したほうがよいもの（本文が空、時間が重なっている、など）
  △ … 見る人が読み切れないおそれ（1 行が長い、1 秒あたりの文字数が多い、
       表示が短すぎる／長すぎる）

  しきい値は「編集 → 設定」で変えられます。


────────────────────────────────────────────────────────────
■ 初回に取得される部品について
────────────────────────────────────────────────────────────

  このソフト自体には、音声や映像を扱う機能は入っていません。
  実際の処理は FFmpeg という定番ソフトが行います（約 73 MB）。

  置き場所:
      C:\Users\（ユーザー名）\AppData\Local\johukku\bin

  同梱せずに取得する形にしているのは、次の理由からです。

  ・FFmpeg は GPL というライセンスのソフトです。同梱して配ると
    配布側にソースコードの提供義務が生じます。公式の配布元から
    利用者の PC が直接取得する形なら、その心配がありません。
  ・「Whisper 字幕作成ツール」「メディアダウンローダー」
    「メディアコンバーター」と同じ場所を使うので、
    すでに入っていれば取得は省かれます。


────────────────────────────────────────────────────────────
■ 警告が出たときは
────────────────────────────────────────────────────────────

  【「Windows によって PC が保護されました」と出る】

     このソフトには有料の署名（デジタル証明書）を付けていないため、
     初回起動時に表示されます。
     「詳細情報」→「実行」で起動できます。

  【ウイルス対策ソフトが反応する】

     この種のツールは誤検知されることがあります。
     心配な場合は、下記でソースコードを公開しているので
     中身を確認してください。

         https://github.com/johukku/subtitle-editor


────────────────────────────────────────────────────────────
■ うまくいかないときは
────────────────────────────────────────────────────────────

  【動画を開いても音が出ない・波形が出ない】

     動画に音声が入っていない可能性があります。
     その場合はコマの表示だけ使えます。
     「ヘルプ → 部品を入れ直す」で FFmpeg を取得し直すと
     直ることもあります。

  【字幕が化けて読める形になっていない】

     文字コードを自動で判定していますが、古い形式のファイルは
     読み違えることがあります。メモ帳で開いて「UTF-8」で
     保存し直してから開いてください。

  【焼き込みが失敗する】

     グラフィックドライバが古いと GPU での書き出しに失敗します。
     焼き込みの画面で「GPU が使えれば使う」のチェックを外すと、
     CPU で書き出します。

  【それでも直らない】

     状況を添えて、下記からご連絡ください。

         https://johukku.pages.dev/about/


────────────────────────────────────────────────────────────
■ 削除したいときは
────────────────────────────────────────────────────────────

  「アンインストール.bat」をダブルクリックしてください。
  このフォルダと設定ファイルを削除します。

  ほかのソフトと共有しているもの（FFmpeg）は、消すかどうかを聞きます。
  迷ったら Enter（残す）で大丈夫です。
  消しても、次に使うときにもう一度ダウンロードされるだけです。

  このフォルダに字幕や動画など、ツール以外のファイルを置いていた場合は、
  そのファイルは消さず、フォルダも残します。

  レジストリなどは変更していないので、手で削除してもかまいません。
  その場合は、このフォルダに加えて下記を削除してください。

      C:\Users\（ユーザー名）\AppData\Local\johukku\subtitle-editor  … 設定
      C:\Users\（ユーザー名）\AppData\Local\johukku\bin              … FFmpeg（共有）
